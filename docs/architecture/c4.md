# Architecture: high-level components

Irudd Factory is a TypeScript service on one dedicated VM. It watches
configured GitHub repositories, selects eligible issues, creates isolated
per-issue workspaces, and runs coding-agent sessions in them. A tailnet-served
console lets the single operator monitor and control that work.

Codex CLI is the only harness today. The provider runner is a seam, so room is
left for more harnesses later.

Three rules shape the design and appear in every layer below:

- Only issues whose author has write permission to the repository are eligible.
- `gh` and Codex run with the operator's ambient credentials; the service
  mints, injects, and stores no tokens.
- Writable roots are the containment: an agent writes only to its workspace and
  that workspace's `.git` directory. Reads are unrestricted on the VM.

The trades these imply are recorded in
[SECURITY-LIMITATIONS.md](../../SECURITY-LIMITATIONS.md). The technology choices and
conventions behind these components are in [stack.md](../stack.md).

## Containers

```mermaid
C4Container
title Containers

Person(operator, "Operator", "Reviews, guides, and controls automated implementation work")

System_Ext(agent_providers, "Agent harness CLIs", "Codex CLI today; room for more harnesses")

Container_Boundary(factory, "Irudd Factory") {
    Container(console, "Operator Console", "TypeScript", "Displays assignments, sessions, provider state, logs, and operator controls.")
    Container(dispatcher, "Dispatcher daemon", "TypeScript", "Polls GitHub, selects eligible issues, reserves assignments, manages workspaces, and runs agent sessions.")
    Container(state_store, "State store", "SQLite", "Holds every durable fact: assignment history, provider state, session identifiers, restart recovery, and run diagnostics.")
}

Rel(operator, console, "Uses to monitor and control runs")
Rel(tailnet, console, "Provides private access")
Rel(console, dispatcher, "Reads status and sends operator commands")
Rel(dispatcher, state_store, "Reserves assignments, persists state transitions, and records run diagnostics")
Rel(dispatcher, github, "Reads candidates and writes attribution comments and pull-request links")
Rel(dispatcher, agent_providers, "Launches and supervises harness sessions with ambient credentials")
Rel(dispatcher, vm, "Runs on the VM")
```

## Dispatcher components

```mermaid
C4Component
title Dispatcher daemon components

Container_Boundary(dispatcher, "Dispatcher daemon") {
    Component(candidate_selection, "Candidate selection", "TypeScript", "Finds open, correctly labelled, unclaimed, unblocked issues whose author has write permission, using stable ordering.")
    Component(assignment_coordinator, "Assignment coordinator", "TypeScript", "Reserves issues, enforces one active session per provider, and records state transitions.")
    Component(provider_runners, "Provider runners", "TypeScript", "Launches a harness with ambient credentials and consumes structured session events. Codex CLI today.")
    Component(workspace_manager, "Workspace manager", "TypeScript", "Creates app-owned clones, worktrees, and branches, and names the writable roots for each run.")
    Component(reconciler, "Reconciliation and stall handling", "TypeScript", "Stops work whose issue is no longer eligible and terminates sessions that stop emitting events.")
    Component(pr_attribution, "Pull-request attribution", "TypeScript", "Finds implementation pull requests and adds an idempotent attribution comment.")
}

Rel(candidate_selection, assignment_coordinator, "Offers eligible issues for reservation")
Rel(assignment_coordinator, workspace_manager, "Creates an isolated workspace for a reserved issue")
Rel(assignment_coordinator, provider_runners, "Starts one harness session for an assignment")
Rel(provider_runners, reconciler, "Reports provider events and liveness")
Rel(reconciler, assignment_coordinator, "Updates or stops stale and invalid assignments")
Rel(provider_runners, pr_attribution, "Provides completed-run identifiers and results")
Rel(pr_attribution, assignment_coordinator, "Records final run state")
```
